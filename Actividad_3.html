Punto 1: Mecánica y Arquitectura del Código

El script se basa en el uso de la librería pynput.keyboard de Python. Esta librería actúa como un "hook" (gancho) a nivel de sistema, registrando los eventos del teclado en segundo plano.

Desglose de Componentes

1. El Listener (Hooks de Sistema)

El núcleo del script es la clase Listener. Al iniciarse, se suscribe a los eventos globales del sistema operativo. Esto significa que capta las teclas presionadas sin importar en qué aplicación tengas el foco activo (navegador, editor de código, escritorio).

2. Callbacks (Funciones de Evento)

El código define dos funciones: on_press y on_release. Cada vez que el usuario presiona una tecla, el sistema ejecuta la primera; al soltarla, ejecuta la segunda. Esto permite distinguir si el usuario mantiene una tecla presionada (para repetir caracteres) o si es una pulsación rápida.

3. Captura de Teclas Especiales

El código no solo registra letras y números, sino también teclas de control como Key.backspace, Key.cmd (tecla Windows) o Key.shift. Esto es crucial para reconstruir con precisión combinaciones de teclado (como Ctrl+C).

4. Formato y Escritura de Datos

Se utiliza la librería datetime para obtener la fecha y la hora exacta en milisegundos. Cada evento se convierte en una cadena de texto formateada (Ej: 2026-08-24 23:16:31.828 PRESS x) y se escribe en un archivo de texto .txt en modo append ('a') para no sobrescribir los registros anteriores.

Procesos en segundo plano

Consumo de recursos mínimo

Al ser un script ligero en Python, no ocupa gran cantidad de memoria RAM ni CPU. Esto lo hace difícil de detectar para un usuario común, ya que no genera ventanas ni notificaciones visibles.

Análisis de la evidencia (keylog.txt)

Al abrir el archivo generado, se puede ver la estructura exacta del registro: Timestamp → Tipo de Evento → Tecla. Los microsegundos registrados permiten trazar una línea de tiempo exacta de la actividad del usuario, lo que es vital en un análisis forense digital.

Contexto de Ciberseguridad

Aunque el código es legítimo para monitorización de equipos propios (auditorías internas, pruebas de pentesting con autorización), el mismo script ejecutado de forma encubierta se convierte en una herramienta de spyware. Entender su mecánica permite a los administradores de sistemas detectar procesos sospechosos y bloquear el uso de librerías de captura de teclado en entornos críticos.
