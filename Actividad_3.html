Punto 1: Análisis del Código (Funcionamiento)

El script de Python mostrado en la evidencia (Actividad_3.py) utiliza la librería pynput para crear un listener global de eventos de teclado. Su funcionamiento técnico es el siguiente:

Desglose de Funcionalidades

Captura de Eventos

El programa monitorea constantemente el sistema operativo para detectar dos tipos de eventos: pulsación de teclas (PRESS) y liberación de teclas (RELEASE), incluyendo teclas especiales como Key.backspace, Key.cmd y Key.shift.

Registro Temporal (Timestamps)

Como se observa en el keylog.txt, cada evento es registrado con una marca de tiempo precisa (año, mes, día, hora, minuto, segundo y microsegundo), lo que permite reconstruir la línea de tiempo exacta de la actividad del usuario.

Persistencia en Archivo

Toda la información es volcada a un archivo de texto plano (keylog.txt) en tiempo real. Este método de registro es simple pero efectivo para almacenar datos sin necesidad de una base de datos compleja.

Impacto y Consideraciones de Seguridad

Riesgo de Malware y Spyware

Es un mecanismo clásico de malware sigiloso. Si este código se ejecuta sin el consentimiento del usuario, puede robar credenciales bancarias, contraseñas de correos, mensajes privados y otra información altamente sensible, violando la privacidad y las leyes de protección de datos.

Herramienta de Auditoría y Penetración (Pentesting)

En el lado defensivo, es una herramienta legítima para pruebas de penetración. Los auditores la utilizan (con autorización explícita por escrito) para evaluar la seguridad de una empresa, verificar si los empleados caen en phishing o para realizar análisis forense digital en equipos comprometidos.

Detección y Mitigación

La identificación de este código es sencilla para los antivirus modernos. Las defensas incluyen el uso de sistemas de detección de intrusiones (IDS), la monitorización de procesos extraños en el Administrador de Tareas, la educación del usuario para evitar descargas maliciosas y el uso de gestores de contraseñas con autenticación multifactor (que hace casi inútil el robo de contraseñas simples).
