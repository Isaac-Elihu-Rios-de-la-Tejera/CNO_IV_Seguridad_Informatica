Laboratorio 01: SIMPLE CASE

Descripción técnica:Descripción técnica de lo realizado: Durante el desarrollo de la actividad, se explotó una vulnerabilidad de Path Traversal (CWE-22) manipulando la petición HTTP GET que utiliza la aplicación para cargar imágenes de productos. Se interceptó el tráfico y se modificó el parámetro filename, inyectando un payload de salto de directorio (../../../../etc/passwd). Al reenviar la petición, el servidor procesó la ruta sin validación, permitiendo evadir el directorio raíz de la web y retornando el contenido del archivo sensible del sistema operativo Linux. Herramientas utilizadas: Burp Suite (Community Edition): Utilizado para la interceptación de la petición y el uso del módulo Repeater para manipular y reenviar el payload. Navegador Web: Empleado para interactuar con la aplicación vulnerable y verificar el estado del laboratorio. PortSwigger Web Security Academy: Plataforma que aloja el entorno seguro de pruebas. Objetivos cumplidos: Identificar la vulnerabilidad de salto de directorio en la carga de archivos. Manipular con éxito la petición HTTP para evadir las restricciones de directorio. Extraer y visualizar información sensible del servidor (archivo /etc/passwd). Resolver exitosamente el laboratorio, obteniendo la confirmación de "Lab Solved".
